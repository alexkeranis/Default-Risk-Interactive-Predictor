Method

What changed from the original project

The original README reported PyTorch macro F1 0.84 vs XGBoost 0.75. An audit found that the network was early-stopped and checkpointed on the test set, and that XGBoost was trained without the categorical features. Under a leak-free protocol the gap disappears: all three families are statistically tied on macro F1, and the network is the weakest on log loss. Read the audit · Full benchmark report.

Protocol

  • Stratified 80/20 development/test split. The test set is scored exactly once.
  • One scikit-learn pipeline (imputation → domain features → encoding → model → calibration) fit inside every fold. The same serialized object serves single and batch inference.
  • Equal tuning budget per family, inner 5-fold CV, scored by log loss (a proper scoring rule).
  • Repeated stratified 5×3 CV for model comparison, with the Nadeau–Bengio corrected t-test. A pre-registered 1-SE rule prefers the simpler model.
  • Post-hoc calibration (sigmoid, isotonic or temperature) chosen on out-of-fold Brier score. Cutoffs are chosen on out-of-fold predictions.

How the browser reproduces the model

The pipeline exports the fitted coefficients, tree structures, imputation medians and calibration maps to JSON. assets/model.js re-implements only arithmetic. A CI test checks it against predictions from the fitted Python pipelines: logistic regression to 1e-9, and XGBoost to 1e-5 (XGBoost accumulates in float32). Driver attributions are exact for logistic regression and Saabas path attributions for XGBoost, in log-odds space.

Limitations

  • Synthetic labels: a near-deterministic rule on debt-to-income, late payments and employment, so scores here overstate what real bureau data allows.
  • Tiers are not defaults: every dollar figure depends on the assumed PD per tier.
  • No time dimension: there are no vintages, so no out-of-time validation and no drift monitoring.
  • No fairness review: age and employment status are protected or sensitive in many jurisdictions and would need legal review before any real use.
